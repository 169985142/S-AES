## 1. 项目简介

本项目是《密码编码学与网络安全——原理与实践（第 8 版）》附录 D“简化 AES（S-AES）”的教学实现，提供桌面 GUI，用于演示 16 bit 分组、16 bit 密钥、2 轮结构的 S-AES 加密流程。

本仓库只实现**加密方向**，不实现解密、中间相遇攻击和 CBC 工作模式。目标是把算法流程、密钥扩展和多重加密组合讲清楚，并保证输入输出可复现、可测试。

## 3. 功能一览

1. **基础加密**：输入 4 位十六进制明文和 4 位十六进制密钥，输出 4 位十六进制密文；显示 K0/K1/K2、密钥扩展字 w0–w5 和 8 个中间状态。
2. **ASCII 加密**：输入 ASCII 字符串，按每 2 个字节一个分组加密；奇数长度末尾补 1 字节 `0x00` 并明确提示；输出转义 ASCII、十六进制和逐分组结果。
3. **多重加密**：
   - 双重加密：8 位十六进制密钥，前 4 位为 K1、后 4 位为 K2；
   - 三重加密：12 位十六进制密钥，依次为 K1、K2、K3；
   - 展示每一级加密后的 16 bit 中间密文。
4. **交互细节**：输入校验、错误提示、复制结果、载入示例、清空、`Ctrl+Enter` 加密、`Ctrl+L` 清空。

### 4.3 标准示例

| 项目 | 值 |
| --- | --- |
| 明文 P | `6F6B` |
| 密钥 K | `A73B` |
| 密文 C | `0738` |

该向量来自 S-AES 的经典 ASCII 示例：密钥 `1010 0111 0011 1011`，明文 `"ok"`（`0110 1111 0110 1011`），密文 `0000 0111 0011 1000`。

## 5. 输入规则

### 5.1 十六进制输入

- 第 1 关：明文、密钥各 4 位十六进制，例如 `6F6B`、`A73B`。
- 双重加密：密钥 8 位十六进制，例如 `2D55A73B`。
- 三重加密：密钥 12 位十六进制，例如 `2D55A73B1C27`。
- 允许空格、`0x` 前缀和大小写混用；解析前会统一清理。
- 位数不足、位数过多或含非十六进制字符时，界面内显示具体错误，不执行加密。

### 5.2 ASCII 输入

- 只接受 ASCII 字符（码点 0x00–0x7F）；中文、emoji 等非 ASCII 字符会被拒绝并提示位置。
- 每 2 个字节组成一个 16 bit 分组，采用大端顺序：`byte0 << 8 | byte1`。
- 字节数为奇数时，末尾补 1 字节 `0x00`，界面显示补零数量。
- 密文可能包含不可打印字符，因此以 `\xNN` 转义形式展示，同时提供十六进制结果。

## 7. 算法要点

- 分组长度：16 bit，表示为 2×2 半字节状态矩阵。
- 密钥长度：基础 16 bit；双重 32 bit；三重 48 bit。
- 轮数：2 轮；最后一轮不做列混合。
- 有限域：GF(2^4)，本原多项式 `x^4 + x + 1`（`0x13`）。
- 轮密钥：由 16 bit 主密钥扩展为 6 个 8 bit 字，得到 K0、K1、K2。
- 轮常量：第一次扩展 `0x80`，第二次扩展 `0x30`。
- 三重加密顺序：`C = E_K3(E_K2(E_K1(P)))`。

## 8. 测试与验收

### 8.1 自动测试

```bat
python -m pytest -q
```

本机结果（Windows 10 / Python 3.9.9 / PyQt5 5.15.11 / pytest 8.4.2）：

```text
...................                                                      [100%]
19 passed in 0.03s
```

测试覆盖：

- 经典标准向量：`E_A73B(6F6B) = 0738`；
- 密钥扩展：`A73B → A7 3B 1C 27 76 51`；
- 同一输入重复加密结果一致；
- 单比特密钥变化导致密文变化；
- ASCII 偶数字节、奇数字节补零、分组边界；
- 双重加密等于两次单分组加密的顺序组合；
- 三重加密等于三次单分组加密的顺序组合；
- 非法十六进制输入被拒绝。

### 8.2 关键示例

| 功能 | 输入 | 输出 |

## 10. 已知限制

- 仅加密，不提供解密；因此无法在程序内做加密—解密回环验证。
- ASCII 奇数长度采用补 `0x00`，不做自动去填充；这是本作业范围内的约定。
- 三重加密采用三密钥 EEE 模式，未实现双密钥的 EDE 模式。
- 未与其他小组进行真实交叉测试；第 2 关只提供标准向量和复现步骤。
- 未实现 CBC、中间相遇攻击和侧信道防护；本程序仅用于教学演示，不应处理真实敏感数据。
