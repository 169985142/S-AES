# S-AES 加密实验台

> 课程：信息安全导论 · 作业 2
> 版本：v1.0.0
> 说明：本项目已实现 S-AES 加密、解密、扩展功能、多重加密、中间相遇攻击及 CBC 工作模式。

## 1. 项目简介
本项目是《密码编码学与网络安全》附录 D“简化 AES（S-AES）”的完整实现。包含加解密核心算法、PyQt5 桌面 GUI，并完成了交叉测试接口封装、扩展 ASCII 加密、多重加密、中间相遇攻击破解以及 CBC 工作模式与密文篡改实验。

## 2. 功能清单（对应作业要求）
| 关卡 | 要求内容 | 实现情况 |
| :--- | :--- | :--- |
| **第 1 关** | 16-bit 基础加密与解密 | ✅ 完成。提供 GUI 交互，展示密钥扩展与 8 个中间状态。 |
| **第 2 关** | 交叉测试 | ✅ 完成。接口完全解耦，提供标准 API 供异构系统联调。 |
| **第 3 关** | ASCII 字符串加密 | ✅ 完成。自动按 2 字节分组，奇数长度补 0x00，支持转义显示。 |
| **第 4.1 关** | 双重加密 (32-bit) | ✅ 完成。E_K2(E_K1(P))，展示两级中间密文。 |
| **第 4.2 关** | 中间相遇攻击 | ✅ 完成。基于明密文对，1 秒内自动爆破破解 K1、K2。 |
| **第 4.3 关** | 三重加密 (48-bit) | ✅ 完成。E_K3(E_K2(E_K1(P)))，支持三密钥 EEE 模式。 |
| **第 5 关** | CBC 工作模式 | ✅ 完成。支持自定义 IV 进行加解密，内置密文篡改篡改演示功能。 |

## 3. 自动化测试结果
本项目包含严格的单元测试，覆盖了标准向量、逆运算互逆性、CBC 链路及攻击算法。
在终端运行 `python -m pytest tests/ -v`，**全部 20 项测试用例均一次性通过**。

## 5. 快速开始
### 环境要求
- Windows 10/11
- Python 3.9+（推荐 3.10 以上）
- PyQt5 5.15+

### 启动方式
双击根目录下的 `start.bat` 启动脚本，程序会自动检测并安装依赖并启动 GUI。
或者手动在命令行中执行：
```bash
pip install -r requirements.txt
python main.py
